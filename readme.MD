# Doatecas

**Nota importante:** O **Doatecas** não é um site real de doações. Este é apenas um projeto desenvolvido para fins de treinamento e demonstração das minhas habilidades em desenvolvimento de software. O objetivo deste repositório é mostrar os meus projetos e como eles são criados.

## Sobre o Projeto

O **Doatecas** é uma aplicação de exemplo que simula um site de doações. O projeto foi desenvolvido com o objetivo de facilitar a doação de recursos para **crianças necessitadas**, **animais abandonados** e **cestas básicas** para famílias em situação de vulnerabilidade social. 

O objetivo deste projeto é fornecer uma plataforma onde as pessoas podem fazer doações para diferentes causas sociais e ajudar quem mais precisa.

## Funcionalidades

- Cadastro e login de usuários
- Visualização de causas para doação (crianças, animais, cestas básicas)
- Opção de fazer doações financeiras ou de recursos
- Acompanhamento das doações realizadas
- Informações sobre as causas e as organizações beneficiadas
